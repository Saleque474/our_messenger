# Our Messenger

A modern messaging application built with Flutter, designed to provide a seamless communication experience across multiple platforms.

## Features

- Cross-platform support (iOS, Android, Linux)
- Modern UI design
- Real-time messaging capabilities
- Dark mode support

## Getting Started

### Prerequisites

To run this project, you'll need:

- Flutter SDK (stable channel)
- Android Studio / VS Code with Flutter extensions
- For iOS development: Xcode (Mac only)
- For Linux development: GTK development headers

### Installation

1. Clone the repository:
```bash
git clone [your-repository-url]
```

2. Navigate to the project directory and install dependencies:
```bash
flutter pub get
```

3. Run the application:
```bash
flutter run
```

### Building for Different Platforms

#### Android
```bash
flutter build apk
```

#### iOS
```bash
flutter build ios
```

#### Linux
```bash
flutter build linux
```

## Project Structure
